# kurumsal-web-tasar-m-at-lyesi
Web siteniz "Görsel Kod Atölyesi" başlığını taşıyor. Sitenin temel konusu ve amacı interaktif ve eğlenceli bir şekilde temel web tasarımı prensiplerini öğretmektir.

Sitede yer alan 5 ana konu ve işlevleri şunlardır:

🎨 Renk Uyumu (Palet Sihirbazı): 
Ana ve yardımcı renk kavramlarını, kontrastı ve doğru renk kombinasyonlarını canlı renk seçicilerle deneyimletir.

✍️ Yazı Karakterleri (Font Deneme Sürüşü): 
Tipografinin ve font uyumunun önemini vurgular, farklı font çiftlerini canlı olarak denetir.

📱 Duyarlı Tasarım (Mobile Uyum): 
Web sitelerinin masaüstü ve mobil ekranlarda nasıl şekil değiştirdiğini gösterir.

📐 Boşluk Kullanımı (Padding/Margin): 
İç boşluk (padding) ve dış boşluk (margin) kavramlarını kaydırıcılar (slider) ile görselleştirir.

👁️ Görsel Odak (Hiyerarşi): 
Kullanıcının dikkatini çekmek istenen ana öğelerin nasıl vurgulandığını tıklanabilir kutularla öğretir.
